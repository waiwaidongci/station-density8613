# 测试说明（gb-0042）

## 复算包与离线核验：`test_recalc.py`

```bash
python3 test-artifacts/gb-0042/test_recalc.py
```

纯标准库，无需启动服务。覆盖：

- 已知答案 oracle：手工核算的两个紧致簇+离群站（全核心+噪声）、等距链式布站（核心/边界混合），逐站比对簇编号与微站类型；参数越界拒绝。
- 打包结构：清单字段、逐批 SHA256、批次区间连续、样本与明细逐行对齐、旧结果（无版本戳）按初版锁定。
- 端到端 CLI：全量通过出凭据且幂等；乱序分批到达、缺批待补（退出码2）、补批续验、无变化重跑跳过已验批次。
- 进度安全：已验批次被改动拒用旧进度；换包（清单摘要变化）拒用旧进度；`--reset` 后重验。
- 差异判定：簇整体改号仍通过；簇成员被换、噪声判定被改均失败且只出差异报告不出凭据。
- 算法版本：未知版本明确拒绝；注册表存在新版本时旧包仍按包内锁定版本复算（版本分发单测）。
- 环境装有 numpy/sklearn 时，自动追加与线上 `calculate()` 的真实对照（沙箱无依赖时显示 SKIP）。

其余测试（HTTP 完整流程、Playwright 浏览器流程）见本目录既有用例。
