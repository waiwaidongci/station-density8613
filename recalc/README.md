# 离线复算核验器（recalc）

外业收到密度明细后，用本工具离线确认结论能否采用。纯 Python 3 标准库，零依赖，拷贝 `verify.py` 即可离线运行。

## 复算包

在“完整结果”页面对已完成研究点击 **下载复算包**，得到 `recalc-run-<任务号>-<摘要>.zip`，解包后：

```text
manifest.json            清单：包编号、研究号、冻结参数、算法版本、输入校验和、批次清单及逐批 SHA256
batches/batch-000.json   冻结样本批次 + 该区间预期密度明细（保持原样本顺序切片）
batches/batch-001.json
...
```

## 核验

```bash
python3 verify.py /path/to/recalc-run-3-xxxxxxxxxxxx
```

- **分批乱序到达**：批次文件可随多次拷贝陆续放入包目录，任意顺序均可验收；每批按清单 SHA256 核对。
- **缺批续验**：批次未齐时工具列出待补批次并以退出码 `2` 结束；补到后重新执行同一命令即可续验。
- **中断恢复**：验收进度保存在包目录 `.recalc-progress.json`，恢复时自动跳过已验批次。
- **拒用旧进度**：换包（清单摘要变化）或已验批次被改动时，工具拒绝沿用旧进度并以退出码 `1` 结束；确认来源无误后用 `--reset` 清空重验。
- **逐站复算**：批次到齐后按原样本顺序逐站复算，核对噪声判定与簇成员；簇编号整体改号不算差异。
- **核验凭据**：仅当全部相符才写出 `verification-credential.json`（含包编号、算法版本、参数、输入校验和、清单摘要、核验时间与凭据摘要）；任何不符只出差异报告 `recalc-report.json`，不出凭据。
- **算法版本**：复算严格按包内 `algorithm_version` 执行；核验器保留各版本实现，算法升级后旧包仍按原版计算，遇到不认识的版本会明确拒绝。

退出码：`0` 核验通过（或该包已完成核验）；`1` 核验失败 / 包异常；`2` 批次未齐。

```bash
python3 verify.py PKG --reset                 # 清空旧进度、凭据与报告后重新验收
python3 verify.py PKG --credential out.json   # 指定凭据输出路径（--report 同理）
```

包目录需可写（进度、凭据、报告默认写入包目录）。核验通过后，凭据摘要可与清单摘要、输入校验和一起回传，供组内对照网页端结果页的 SHA256。
